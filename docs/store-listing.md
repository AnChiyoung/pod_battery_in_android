# Play 스토어 등록 정보 (초안)

## 앱 이름 (30자 이내)
PodBattery - 이어폰 배터리

## 간단한 설명 (80자 이내)
케이스를 두 번 톡톡 하면 AirPods 왼쪽·오른쪽·케이스 배터리를 1% 단위로 보여줍니다.

## 자세한 설명 (4000자 이내)
AirPods의 배터리 잔량을 1% 단위로 확인하고, 잠금화면 알림에 남겨 두는 앱입니다.

■ 사용 방법
1. 이어폰을 케이스에 넣고 뚜껑을 엽니다.
2. 케이스 앞면을 두 번 톡톡 두드립니다. (뒷면에 버튼이 있는 모델은 버튼을 길게 누릅니다.)
3. 표시등이 흰색으로 깜빡이면 몇 초 안에 배터리가 표시됩니다.
앱을 닫아 두어도 확인되며, 마지막으로 확인한 값과 시각이 알림에 남습니다.

■ 기능
• 왼쪽 / 오른쪽 / 케이스 배터리를 1% 단위로 표시
• 충전 중 ⚡ 표시, 20% 이하 빨간색 표시
• 잠금화면 알림으로 바로 확인

■ 안내
• AirPods 전용입니다. 다른 회사의 이어폰은 지원하지 않습니다.
• AirPods가 페어링 모드일 때만 배터리 정보를 보내기 때문에, 확인할 때마다 케이스를 두드리는 동작이 필요합니다.
• 배터리 표시 외의 기능(소음 제어, 설정 변경 등)은 없습니다.
• Android 12 이상에서 동작합니다.

■ 개인정보
• 개인정보를 수집하지 않으며, 인터넷 권한을 사용하지 않습니다.
• 근처 기기 권한은 AirPods의 배터리 신호를 읽는 데에만 쓰며, 위치를 알아내지 않습니다.

AirPods는 미국 및 기타 국가에서 등록된 Apple Inc.의 상표입니다. PodBattery는 Apple Inc.의 공식 앱이 아닙니다.
