# Play 스토어 등록 정보 (초안)

## 앱 이름 (30자 이내)
PodBattery - 이어폰 배터리

## 간단한 설명 (80자 이내)
무선 이어폰을 연결하면 왼쪽·오른쪽·케이스 배터리를 잠금화면 알림에 바로 보여줍니다.

## 자세한 설명 (4000자 이내)
이어폰을 연결하는 순간, 배터리가 잠금화면에 뜹니다.

PodBattery는 무선 이어폰의 왼쪽, 오른쪽, 케이스 배터리 잔량을 한눈에 보여주는 앱입니다.
앱을 따로 켤 필요 없이, 이어폰이 연결되면 자동으로 시작해 잠금화면과 알림창에 배터리를 표시합니다.

■ 주요 기능
• 왼쪽 / 오른쪽 / 케이스 배터리를 각각 표시
• 충전 중이면 ⚡ 표시, 20% 이하이면 빨간색으로 강조
• 이어폰 연결 시 자동 시작, 연결이 끊기면 자동 종료
• 잠금화면에서 바로 확인
• 다크 모드 지원

■ 이용 안내
• 케이스 배터리는 이어폰이 케이스 안에 있을 때만 전달됩니다. 이어폰을 꺼낸 뒤에는 마지막으로 확인한 값이 "케이스(이전)"으로 표시됩니다.
• Apple 프로토콜을 쓰는 무선 이어폰을 지원합니다. 일부 기기나 펌웨어에서는 동작하지 않을 수 있습니다.

■ 개인정보
• 개인정보를 수집하지 않으며, 인터넷 권한을 사용하지 않습니다.
• 블루투스 권한은 연결된 이어폰의 배터리를 읽는 데에만 사용합니다.

AirPods는 Apple Inc.의 상표입니다. PodBattery는 Apple Inc.와 관련이 없으며, Apple의 승인이나 후원을 받지 않았습니다.

도구

## 콘텐츠 등급
전체이용가 (설문에서 폭력·선정성 등 모두 "아니요")

## 데이터 보안 양식
• 데이터 수집: 없음
• 데이터 공유: 없음

## 포그라운드 서비스 신고 (connectedDevice)
• 용도: 연결된 블루투스 이어폰의 배터리 잔량을 계속 받아 알림에 표시
• 사용자에게 보이는 동작: 이어폰이 연결된 동안 진행 중 알림이 표시되고, 알림의 "중지" 버튼으로 끌 수 있음
• 중단 시 영향: 서비스가 없으면 이어폰과의 연결이 끊겨 배터리를 갱신할 수 없음
• 시연 영상: 이어폰 연결 → 알림 표시 → 중지 버튼 순서로 30초 내외 화면 녹화
