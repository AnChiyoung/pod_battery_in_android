# Play 스토어 등록 정보 (초안)

## 앱 이름 (30자 이내)
PodBattery - 이어폰 배터리

## 간단한 설명 (80자 이내)
AirPods를 연결하면 왼쪽·오른쪽·케이스 배터리를 잠금화면 알림에 보여줍니다.

## 자세한 설명 (4000자 이내)
AirPods의 배터리 잔량을 안드로이드 잠금화면과 알림창에 보여주는 앱입니다.

■ 기능
• 왼쪽 / 오른쪽 / 케이스 배터리 표시
• 충전 중 ⚡ 표시, 20% 이하 빨간색 표시
• 이어폰 연결 시 자동 시작

■ 안내
• AirPods 전용입니다. 다른 회사의 이어폰은 지원하지 않습니다.
• 케이스 배터리는 이어폰이 케이스 안에 있을 때만 갱신됩니다.
• 배터리 표시 외의 기능(소음 제어, 설정 변경 등)은 없습니다.

■ 개인정보
• 개인정보를 수집하지 않으며, 인터넷 권한을 사용하지 않습니다.

AirPods는 미국 및 기타 국가에서 등록된 Apple Inc.의 상표입니다. PodBattery는 Apple Inc.의 공식 앱이 아닙니다.

## 카테고리
도구

## 콘텐츠 등급
전체이용가 (설문에서 폭력·선정성 등 모두 "아니요")

## 데이터 보안 양식
• 데이터 수집: 없음
• 데이터 공유: 없음

## 포그라운드 서비스 신고 (connectedDevice)
• 용도: 연결된 블루투스 이어폰의 배터리 잔량을 계속 받아 알림에 표시
• 사용자에게 보이는 동작: 이어폰이 연결된 동안 진행 중 알림이 표시되고, 알림의 "중지" 버튼으로 끌 수 있음
• 중단 시 영향: 서비스가 없으면 이어폰과의 연결이 끊겨 배터리를 갱신할 수 없음
• 시연 영상: 이어폰 연결 → 알림 표시 → 중지 버튼 순서로 30초 내외 화면 녹화
